## 8.6 Git 基础操作
- 今天先提交了一遍下载之后的文件夹，然后把定义闪烁次数的宏从3改成5，然后再次提交。之后船舰了一个分支，并在分支里修改了延时的时间，然后练习了回退，重新修改了一遍.

git操作的顺序：
1. init
1. add .
1. commit -m "备注"
1. checkout
1. log
1. diff
1. merge
   
| reset命令 |	作用|	什么时候用 |	
| --------- | ----- | ---------- |
| init |	在当前文件夹初始化Git仓库 |	第一次新建项目用，只用一次	|
| add . |	暂存当前目录下所有修改 |	修改代码保存后，准备提交存档前	|
| commit -m "备注" |	将暂存区内容存入本地仓库 |	暂存完成后，固定当前代码版本，方便后续回退、查看历史 |
