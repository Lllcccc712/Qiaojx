## 二.git操作的顺序：
1. git init (在当前文件夹初始化一个全新的 Git 本地仓库。)
1. git add . (把当前目录下所有新增、修改过的文件，提交到暂存区。)
1. git commit -m "备注"  (将暂存区的文件打包，生成永久版本快照存入本地仓库。)
1. git checkout  (git checkout 分支名：切换到指定分支；git checkout 提交id：回退到历史某一个旧版本；)
1. git log  (查看仓库所有历史提交记录。)
1. git diff  (对比文件差异，查看修改前后具体改动内容)
1. git merge  (合并分支，把一个分支的代码内容合并到当前分支。)
