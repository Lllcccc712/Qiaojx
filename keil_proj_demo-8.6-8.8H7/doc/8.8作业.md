# 乔靖轩 2026.8.8
## C 语言工程操作
### 一. 修改现象
 1. current_led = 1U 改成 2U，观察从哪颗 LED 开始：每次循环都从第二颗开始闪烁，
 2. BEEP_MS 从 120U 改成 300U，观察蜂鸣器响声长短：蜂鸣器响声明显延长。
 3. delay_ms -= 20U 改成 += 20U，看速度变化方向：闪烁频率越来越慢。
 4. 删掉beep(BEEP_MS) 的调用，观察程序行为：仅LED闪烁，蜂鸣器不响。

#### 4. 循环与分支

| 循环/分支 | 作用 |
| --- | ---- |
| for | 用于控制LED的亮灭 |
| while | 在LED编号 < 总数的条件下，控制LED依次闪烁|
| if | 使LED亮的时间递减，达到100ms后回归初始值 ； 保证LED的序号不超过总数|
| switch | 没找着啊，整体说一下吧，功能类似于多个if分支，即3条及以上的分支可考虑switch循环。假设有一整形变量x，取值为1~5，则switch根据x的取值准备5条分支，x=1时，连接第一条分支，以此类推，x=5，连接第五条分支
